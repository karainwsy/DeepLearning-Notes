## 📖 知识体系架构

本仓库目前包含 51 个精心组织的 `.ipynb` 笔记，涵盖了深度学习从基础到前沿的核心领域：

### 1. 神经网络基石 (L1 - L12)
- **核心模型**：线性回归、Softmax 回归、多层感知机 (MLP)。
- **训练优化**：SGD 优化、过拟合与欠拟合分析、权重衰减、Dropout、模型稳定性。
- **实战案例**：Kaggle 房价预测。

### 2. 计算机视觉CV  (L13 - L24)
- **算子解析**：图像卷积、填充、步幅、多通道计算、池化层。
- **经典架构**：LeNet, AlexNet, VGG, NiN, GoogLeNet, ResNet。
- **工程技巧**：批量规范化 (BN) 的原理与实现。

### 3. 序列模型 (L25 - L38)
- **时序建模**：语言模型、RNN（基础/简洁实现）、GRU、LSTM。
- **深层架构**：深度循环神经网络、双向循环神经网络。
- **端到端任务**：机器翻译数据集处理、编码器-解码器架构、Seq2Seq、束搜索 (Beam Search)。

### 4. 注意力机制与 Transformer (L39 - L45)
- **注意力演进**：从 Nadaraya-Watson 核回归到注意力分数计算。
- **核心突破**：多头注意力、自注意力机制与位置编码 (Positional Encoding)。
- **架构巅峰**：**Transformer 完整架构**。

### 5. 自然语言处理基础NLP (L46 - L57)
- **语义向量**：Word2Vec 原理、负采样近邻训练。
- **技术进阶**：全局向量词嵌入 (GloVe)、子词嵌入 (Subword Embedding)。
- **BERT**：介绍BERT架构，以及下游任务案例
